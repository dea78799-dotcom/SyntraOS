Contributing to SyntraOS

Thank you for your interest in SyntraOS.

Current Development Stage

SyntraOS is currently in the Foundation phase.

Contribution Guidelines

- Keep code clean and readable.
- Use meaningful names for files and functions.
- Document important changes.
- Test changes before submitting.
- Do not submit malicious code.
- Respect project ownership and licensing terms.

Reporting Issues

When reporting an issue, include:

- A clear description.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.

Development Principles

- Security first.
- Modular architecture.
- Hardware independence.
- Code quality.
- Long-term maintainability.
